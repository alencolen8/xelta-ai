## Prompt Writing

Clear prompts can help generative AI systems better understand the desired output.

A useful prompt can describe:

- Subject
- Setting
- Style
- Composition
- Lighting
- Camera or viewpoint
- Mood
- Important details

## Generative AI Workflow

A basic creative workflow can be organized into these steps:

1. Define the content goal.
2. Write a clear prompt or script.
3. Generate an initial result.
4. Review the output for errors.
5. Refine the prompt or content.
6. Select the final result.
7. Prepare the asset for its intended use.
